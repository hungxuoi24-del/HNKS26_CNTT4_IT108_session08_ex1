# Bài 1 : Xử lý xung đột tài liệu trên GitHub

## Phần 1. Phân tích
-	Sai lầm của nam khi dùng file Word:
    - File word không chỉ chứa các ký tự mà nó còn mang theo nhiều thông tin về màu sắc, font chữ, bố cục … Vì vậy, mỗi khi chỉnh sửa hệ thống quản lý như Git sẽ coi như toàn bộ file bị thay đổi, dẫn đến lỗi đè lên nhau.
    - Nam nghĩ markdown thô sơ nhưng khi đưa lên github, trang web sẽ tự động dịch file markdown thành 1 tài liệu có tiêu đề, bố cục dễ nhìn, dễ đọc ngay trên trình duyệt.
-	Markdown an toàn và nhẹ hơn word vì nếu file word mất 1 mảnh dữ liệu khi tải về sẽ bị hỏng hoàn toàn, ngược lại markdown chỉ là plain text nên mất vài chữ thì vẫn đọc được bình thường. Dung lượng markdown cũng nhẹ hơn word.
